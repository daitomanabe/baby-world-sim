# Baby World Simulator（0–4歳 発達シミュレーター）

**目的**：誕生から4歳（0〜48ヶ月 / 0〜208週）までの「世界の獲得」を、**週単位のタイムライン**で操作しながら、  
- 視覚・聴覚（画面/音での近似シミュレーション）  
- 触覚・嗅覚・味覚（再現できないため、グラフ・テキストによる説明）  
- 言語・概念（再現できないため、マイルストーン・推定曲線・注釈で可視化）  
を **“見てわかる”** 形で提示するWebアプリを作る。

> ⚠️ **重要**：本プロジェクトは教育・研究・展示用途の「近似モデル」です。  
> 医療・診断・発達評価（スクリーニングを含む）には使用しないでください。  
> 発達には個人差が大きく、また本アプリは注意・予測・学習など脳内過程を厳密再現するものではありません。

---

## 何ができるアプリか（スコープ）

### ✅ できること（MVP）
- **週単位スライダー**（0〜208週）でタイムライン操作
- **視覚近似**：同一シーンに「年齢に応じた見え方フィルタ（ぼかし/彩度/コントラスト等）」を適用
- **聴覚近似**：WebAudioで合成音を鳴らし、**定位誤差**や**聞き取りやすさ**を年齢で変化
- **触覚/嗅覚/味覚**：再現不可なので、**探索戦略（口→手→道具）**などの説明とグラフ表示
- **言語/概念**：代表的マイルストーン（公的機関/医療機関/査読研究）を週にマッピングし、UIカードで提示
- **出典レベルの明示**：各カードに「出典URL」「レベル（例：公的機関/病院資料/査読論文/概説）」を表示

### ❌ やらないこと（当面）
- 「赤ちゃんの主観体験そのもの」を断定的に再現すること
- 個別の子どもの発達を推定・評価する機能
- 医療的助言、診断、介入の提案

## データについて（最重要）


- 初期リサーチ（マイルストーンの根拠一覧）：`docs/RESEARCH_INITIAL.md`
- 本アプリの中核は **`milestones`（マイルストーン）** と **`curves`（連続パラメータ曲線）** の2種類。
- **週刻みUI**は便利だが、出典は多くが「月/年」単位。したがって週単位の変化は **補間（モデル仮定）** を含む。
- そのため、UI上で  
  - **「根拠ありの節目」**（例：30ヶ月の言語マイルストーン等）  
  - **「補間による推定」**（例：週ごとの滑らかな曲線）  
  を明確に区別する。

## AIと一緒に開発する（方針）
本リポジトリは「GitHubに公開しながらAIの助けを借りて反復開発」する前提で設計する。

- Issue/PR を **AIに渡す単位**として設計する（小さく、再現手順と受け入れ条件を明記）
- `scripts/context_pack.mjs` で **必要なファイルだけ**を束ねてAIに渡す  
- AIの提案は **PRとしてレビュー**し、人間が採用/修正する（自動マージしない）

詳細：`docs/AI_WORKFLOW.md`
