# OVERVIEW（概要）

## 1. コンセプト
「赤ちゃんが世界を獲得していく」過程を、0〜4歳（0〜48ヶ月 / 0〜208週）のタイムライン上で可視化する。

ここでいう“世界の獲得”は、
- 感覚入力（五感）そのものの成熟
- 感覚と運動の協応（探索・操作・移動）
- 言語・概念の形成（理解/産出・共同注意・象徴機能など）
が相互に関係しながら進む、という立場を採る。

## 2. ゴール
- 週単位でタイムラインを動かすと、視覚/聴覚の近似が変化し、同時に言語・概念・運動の節目が理解できる
- 出典・根拠レベルをUIに組み込み、ユーザーが「どの程度の確からしさか」を参照できる
- 展示/教育/研究のコミュニケーションに耐える、誠実な表現（誇張しない）

## 3. 非ゴール（やらない）
- 個別の子どもの発達を評価・診断する
- 「赤ちゃんはこう見えている/こう聞こえている」と断定する
- 治療・介入の推奨

## 4. 表現上の原則（誠実さ）
### 4.1 近似モデルであることを明示
視覚フィルタや聴覚の定位誤差などは、あくまで「代表的傾向の近似」。
脳の注意・予測・学習（トップダウン）を厳密に再現するものではない。

### 4.2 “データ”と“補間”を分ける
- マイルストーン：出典に沿う
- 週ごとの滑らかな変化：補間（仮定）であり、その旨をUIに表示する

### 4.3 個人差を消さない
平均像だけを提示すると誤解を生むため、可能なら将来
- 典型範囲（例：P10–P90）
- 個人差の注釈
を追加する。

## 5. ユーザーストーリー（例）
- 研究者：年齢ごとの変化を俯瞰し、出典リンクから一次情報へ飛べる
- 教育者：子どもへの声かけ・遊びの設計の理解に使う（※介入の推奨ではない）
- 展示来場者：タイムライン操作で「何がいつ頃変わるか」を直感的に理解する

## 6. 倫理・リスク
- 発達の遅れや障害を想起させる可能性があるため、断定表現を避ける
- “標準”という語の使い方に注意（あくまで統計的な典型）
- 医療的誤用を防ぐ導線（免責・説明・外部リンク）を明確にする
