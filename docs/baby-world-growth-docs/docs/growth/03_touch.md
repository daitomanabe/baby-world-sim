# 触覚（探索/固有感覚を含む）（0〜48ヶ月）

PCでは触覚を直接再現できないため、アプリでは **探索のモード（口→手→道具）** をproxyとして扱います。

## アプリでの対応フィールド（JSON）
- `months[n].senses.touch`（mouthExploration / handExploration / toolUse / stage）

## アンカー（根拠の強い節目）
- [ANCHOR] 3ヶ月：手・口で探索が増えるという作業療法ガイド。([Royal Children's Hospital (PDF): Encouraging young babies to use their hands](https://www.rch.org.au/uploadedfiles/main/content/ot/infosheet_t.pdf))
- [ANCHOR] 4ヶ月：安全な物を口で探索することが学習に関係、というCDCの説明。([CDC: Milestones by 4 Months](https://www.cdc.gov/act-early/milestones/4-months.html))


## 発達の概観（区間別 / [ANCHOR]+[MODEL]）

- **0〜3ヶ月**：[ANCHOR] 手で触る/口で探索が増える帯。([Royal Children's Hospital (PDF): Encouraging young babies to use their hands](https://www.rch.org.au/uploadedfiles/main/content/ot/infosheet_t.pdf))
- **4ヶ月**：[ANCHOR] 口で探索することが“学習”の一部として説明される。([CDC: Milestones by 4 Months](https://www.cdc.gov/act-early/milestones/4-months.html))
- **6〜12ヶ月**：[MODEL] 手探索が主役化し、掴む→振る→叩く→入れる/出すなど操作が増える。
- **12〜24ヶ月**：[MODEL] 道具・手順（入れる→閉める→開ける等）が増え、概念（因果/目的）と結びつく。
- **24〜48ヶ月**：[MODEL] 触覚は“操作の精度”として現れやすい（ボタン、ひも通し、ハサミなど：主に微細運動の成果）。

## 実装メモ
- 触覚の再現を目指さない。**行為の変化**（探索モードとタスク）で見せる。
- 口探索は安全上の注意をUIに明示（現実の推奨ではなく説明であることも併記）。
